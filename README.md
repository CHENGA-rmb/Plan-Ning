# ✨ Plan Ning

一个为「深圳国际学校 G9 学生」设计的时间规划应用 —— 以「睡眠和恢复」为硬约束，解决「进度跟不上」和「回家不知道干什么」两个痛点。

## 📁 文件说明

| 文件 | 内容 |
|------|------|
| `index.html` | 可交互原型（单文件，浏览器直接打开即可使用） |
| `DESIGN.md` | 完整产品设计文档：时间账本、睡眠推导、设计原则、核心功能与里程碑 |
| `README.md` | 本说明 |

## 🎮 界面结构（游戏式分屏）

像游戏一样有两层界面：

- **主页面（主菜单）**：Plan Ning 标题 + 当前时间 + 「此刻该做什么」+ 状态栏 + 「▶ 开始今天」+ 6 个模式方块。
- **游玩页面（关卡页）**：点方块进入对应模式，顶部有「← 主页」返回，每个模式是一整屏。

## 🧩 六大模式

1. 📅 **今日时间轴**：一天的时间锚点 + 实时「现在」指针。
2. 🌙 **今晚计划**：添加作业 → 选「今天累吗」→ 生成「学习 + 休息 + 缓冲带 + 熄灯」计划，自动排序并保证不越过熄灯线；作业支持「🙋不会」标记。
3. 😴 **睡眠守护**：改起床时间/目标睡眠，自动反推熄灯时间；可开启熄灯提醒（60/30/15 分钟三档）。
4. 📝 **睡前复盘**：三问复盘 + 「明天问老师」行动清单。
5. 🚌 **通勤助手**：早/晚通勤段的任务分工建议。
6. 🏦 **恢复银行**：每日打卡 + 最近 7 天劳逸平衡周报。

所有数据仅保存在浏览器 localStorage，无需联网。

## 📅 关于课表

已按你的真实课表填入 `index.html` 顶部的 `PERIODS`：

- 上午：8:00 美术 / 8:50 历史 / 9:40 文学 / 10:30 中文 / 11:20 生物 / 12:10 语言
- 下午：13:45 AE 自习 / 14:20 数学 / 15:10 经济

以后调课，只需改 `PERIODS` 这一处，时间轴、实时提示、晚间计划都会自动跟着变。

## 💡 核心设计理念（一句话）

> 先锁死熄灯时间和到家时间两个锚点；回家那一刻自动生成「学习 + 休息 + 缓冲」的晚间计划；每天睡前 5 分钟复盘，把「跟不上」变成「明天要问、要练」的具体行动。休息不是学剩下的，休息是被计划出来的。

详细论证见 `DESIGN.md`。
